# Revit 2020 实机验收清单

1. Revit 2020 中新建项目并先保存 RVT。
2. 确认文件未导入 CAD、未链接 Revit、未建立正式模型构件。
3. 从 Revit 启动 Rhino.Inside.Revit，再打开 Grasshopper。
4. 放置“湖北BIM报规｜01 文件初始化”组件。
5. 确认组件标题显示 Revit 2020 和当前文档名。
6. 在组件内完成项目编号、项目名称、子项、坐标、高程和真北填写。
7. 勾选空白文件确认，执行校验。
8. 点击“写入并回读”。
9. 确认状态为“初始化通过”。
10. 保存并关闭 RVT；重新打开后再次放置或打开组件，确认可读取既有初始化记录。
11. 修改任一初始化值，确认状态变为“已修改待重新提交”。
12. 检查 Revit 撤销列表中初始化为一次完整操作。
