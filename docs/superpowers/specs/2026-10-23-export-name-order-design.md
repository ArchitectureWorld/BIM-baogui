# IFC 导出名称确认（用户已批准）

命名固定为 `OUT_项目名称_阶段_具体单体名称或总图_YYYYMMDD_V1.ifc`。RVT 的可选 `3D_` 前缀不进入输出名称；按最后一个下划线拆分项目与具体单体。旧式横杠名称仅提供建议，导出窗口允许人工确认、修改这两个名称，不改原 RVT 名称和业务属性。

使用一个轻量窗口确认项目名、具体单体名、输出目录并实时预览最终文件名。总图第三段固定为“总图”；阶段沿用人工确认值，类型沿用已有自动识别及冲突确认。缺少具体单体名时要求填写，不能生成泛化的“单体”。默认目录为 RVT 同级，未保存模型回退到文档目录，可浏览选择现有目录。确认后仍执行现有导出核对和完整成功检查。

同目录、同名称和同日期按现有 IFC 及回执等伴随文件最大版本加一，取消窗口不创建文件。保留全模型导出、人工面积优先、平台绑定和所有业务映射。仅合入本地 main 并安装；不改客户模型、不推送远程。

用户追加批准：交付目录只生成 IFC。配置、日志、临时共享参数定义及成功回执移到插件内部记录目录。原生导出先在内部目录完成，模型回滚、服务恢复和一致性核验通过后再发布最终 IFC；平台同步使用真实内部回执。既有历史文件不清理。
