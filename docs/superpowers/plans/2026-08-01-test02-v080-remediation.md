# Test02 v0.8.0 官方插件兼容修复计划

## 目标

基于 `20260731test02.rvt` 与 `20260731test02.ifc` 的实际证据，修复 Stage 01 数据只进入 HBR 存储、未进入官方插件读取参数的问题，并建立重新导出闭环。

```text
旧 RVT 0.2.0 初始化
→ v0.8.0 自动迁移
→ 内部唯一参数 + 官方精确源参数双写
→ 保存 RVT
→ 官方 H-IFC 插件重新导出
→ 新 IFC 深度比对
→ 官方检查软件确认
```

## 已确认失败

- RVT 存储版本：`0.2.0`；
- RVT 中 `HIFC.*` 参数：0；
- IFC 中 H-IFC PropertySet：0；
- IfcProject/IfcSite/IfcBuilding 仍为通用占位值；
- 项目坐标、高程、坐标系和高程系均未导出；
- v0.7.0 的 `HIFC.<Pset>.<Property>` 名称不等于官方配置的精确源参数名。
