## 日常检查与属性管理

入口：**H-IFC V1 → 模型属性管理 → 模型检查 / 属性管理**。

1. 人工选择“报规 / 施工图”，再自动识别或人工选择“总图 / 单体建筑”。
2. 点击“全面检查并补齐属性”，重新读取当前项目的模型构件、边界、项目信息、标高和相关类型。
3. 查看参考项覆盖、参数存在和有效属性值；扫描结束自动生成全项目补齐预览，无需在 Revit 中预选。
4. 核对预览后写入，回读验证后再次全面扫描。缺失载体和待补业务值单独报告；可在清单内定位、修正分类及批量填写。

“缺参数”“未填写”“值非法”“有歧义”“待分类”和“未覆盖”分别显示。已有候选的参考项显示“待确认分类”，与“参考项未找到”分开；构件清单与预览显示识别依据。共享类型字段去重统计，类型修改预览列出受影响实例数。每次检查均重新发现当前模型对象和值，不沿用旧完成状态或排除项。材质、贴图、渲染以及图例、内部草图等辅助定义不参与检查或完成度。详见 [判定依据与边界](docs/模型检查判定依据.md)。

详见 [阶段、类型与全面检查使用说明](docs/Revit2020-0.3.0-全面检查与属性管理.md)。[真实总图窗口](validation/workflow-20261015-123730/总图.0008_干净-after.png)、[真实厂房窗口](validation/workflow-20261015-123730/厂房_干净-after.png)、[真实后勤楼窗口](validation/workflow-20261015-123730/职工后勤楼_干净-after.png) 来自本轮副本实测；`validation/ui-0.3.2/` 的独立布局测试使用模拟数据。

施工图目前只做基础模型盘点，规则待建立。链接模型报告为未覆盖，须在源文档检查。完整 IFC 导出、参考软件同模型 A/B 和平台验收分别验证，不能由窗口完成度替代。
