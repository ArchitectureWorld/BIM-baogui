# H-IFC V1 · 已安装试用 0.4.19-preview.1

`main` 为本版唯一开发主线。当前入口为 Revit 2020 中的 **H-IFC V1 → 模型属性管理 → 模型检查 / 属性管理**。

当前开发及已安装试用版为 **0.4.19-preview.1**，程序集 **0.4.19.0**，上一版 0.4.18-preview.2 已完整备份。文档更新于 **2026-10-23**。本版提供导出名称确认、每日版本序列和仅 IFC 交付；原有分类下拉、布尔复选框、报规 Excel、红线资料及人工面积优先继续保留。见 [本轮开发与验证](docs/0.4.19-导出命名与单文件交付.md)；平台同步仍只读。

0.4.15 引入的净用地控制红线自动填值及写入、建筑用途“中学”、人工面积优先和完整模型导出继续保留。此前总图副本的原生验证见 [0.4.15 记录](docs/0.4.15-净用地控制红线自动赋值.md)。

## 日常操作

**1 人工确认阶段 → 2 模型类型 → 3 全面检查 → 4 写入 Revit**。

窗口全面读取当前模型，无需预选。模型可提供的面积、名称等自动填写；可直接修改右侧属性，必填缺失与修改草稿为红底，回读成功的人工值为橙底。阶段、类型、检查与草稿按模型暂存，重开后仍全面复检。

0.4.9 中，已填写楼层面积会按原区域面积比例同步到本层建筑区域，“4 写入”统一保存；直接原生导出也使用该面积口径，并保持 RVT 源参数和几何。区域范围不完整时先报告核对原因。

- “建筑用途名称”缺失时，左侧建筑技术项和右侧属性标红；待写草稿不解除提示，实际写入并复检后解除。选择“中学”会原值写入、保存及导出，不更改“民用建筑”。具体用途按项目确认，不自动将所有建筑填为中学。
- 仅“区内道路类型＝消防道路”的道路宽度要求手填；未填写时对应类目与属性标红。普通道路、未确定用途的道路及道路红线不适用这条宽度要求。
- “计算设置”集中确认建筑区域/净用地候选、共用业务值和实际楼层；自动值仍经“4 写入 Revit”落入模型。重合净用地防重复写入，面积汇总只采用完整确认且可核对的区域。
- 设置新类目后刷新对应属性和自动值。统一写入时清空旧类目专属实例值，保留共用定义及类型值，失败整体回滚。
- 人防区域、消防分区、停车场和停车位支持原生 Revit 面积（Area），非空专用业务属性优先于面积方案名称，多组专用证据冲突仍待确认；未放置、未封闭及零面积另行报告。新增区域按实际适用，不据此增加必要构件。
- 地上地下作为同一栋建筑表达。“楼层 / 基底 / 基准”用于确认地下建筑楼层、基底楼层及项目标高基准。确认记录按模型保存，全面检查时重新核对；已有手工值、0 和“否”保留，差异单独说明。
- “选中构件赋属性”支持在 Revit 原生选择后人工指定业务类目、编辑并写入所选实例，写入后全面复检。
- 用地红线归为“规划控制线”时，名称与红线类型自动显示“净用地控制红线”，状态为“规则待写入”；写入前仍保留真实原值。已正确填写时不重复修改，清空或改回旧标签会被写入校验提示。其他道路、建筑控制线保留各自业务值。
- 墙、窗仅凭人工分类或专用业务证据归入相应业务类目；普通名称、类别和原生尺寸不构成专用业务分类依据。窗在所选平台配置下按实例输出标高、底高度、宽高，快捷入口不修改共享类型；原案例模式保留类型宽高及整组确认约束。
- 总平构件必须明确分类，按实例输出专属属性。普通楼板的类型文字（例如 250）不再触发总平业务集，原参数保留。
- “计算设置”可选择保康县 420626 的报规规则快照，按项目暂存。右侧属性和共用值使用快照选项及实测兼容选项，主子功能联动；非法旧值保留提示，未知用途和系数不套平台默认值。
- 管理窗口、选中构件赋属性和共用值统一提供可键入的分类下拉：主功能决定子功能候选，切换上级保留旧子级并提示不匹配；多选分类不同显示“多个值”，仅打开和关闭编辑器不产生统一赋值。自定义文字分类可按原文写入、导出，标注平台识别待验证；建筑类别与功能间未经证实的关系不强行绑定。
- 缺失的绿地类型、主子功能、停车配置和红线宽度等会说明平台可能采用的默认值；提示本身不写入模型。“计算设置”的共用值增加公建车位、红线宽度，仍只补空值，保留已有“否”和 0。
- 报规总图的绿化楼板默认生成绿地补齐项；楼板可以手动指定为规划控制线，改回绿地时清理旧类目专属值。
- “导出项目 IFC”默认导出当前项目全部可导出模型，包含 Area 和未分类几何，无需预选，也不受当前视图或管理窗口筛选限制。未闭合 Area 和未覆盖映射在回执列明；链接源文档不自动并入。
- 导出名称为 `OUT_项目名称_阶段_具体单体名称或总图_YYYYMMDD_V1.ifc`；窗口可确认、修改项目及单体名，原 RVT 名称不变。默认同级目录，可自定义；同日递增、按日期独立计数，新一天没有已有文件即从 V1 开始。
- 导出目录只生成 IFC。配置、日志、临时参数和回执由插件内部保存，位置见本轮说明；历史文件不自动清理。
- 导出前可逐项定位缺项，并查看模型面积与本次 IFC 面积。管理窗口里的手工草稿须先点“4 写入 Revit”；关闭窗口后仍有暂存草稿时也会提示，避免导出旧值。
- 插件窗口和 Revit 属性面板的是否属性使用复选框；空值默认“否”。空的建筑基底仍优先按已确认的基底楼层补齐，未确认时首层默认“是”；已有明确值（包括首层人工“否”）保留。旧文字布尔先核验来源、引用和全部绑定值，再随“4 写入 Revit”安全迁移。
- 单体项目信息的建筑类型名称和建筑类别提供预置选项，建筑类别允许补充。预置不会清除已有的其他分类文字。
- 可写的已有值支持直接编辑和写入后再次修改；检查中、结果过期或只读/冲突时显示原因。

只检查模型与属性。材质、贴图、渲染和图例等辅助资源不参与检查。

## 构建与安装

```powershell
pwsh -File tools/Build.ps1
pwsh -File tools/Install-Revit2020.ps1
```

以上命令在 `V1/` 目录执行。构建需本机 Revit 2020 API、自带 IFC 导出程序集、.NET SDK 和 .NET Framework 4.8 开发环境。当前输出及安装默认包为 `dist/Hifc.V1.Revit2020-0.4.19-preview.1/`；本次已按用户要求安装至 `%APPDATA%/Autodesk/Revit/Addins/2020/Hifc.V1/`。构建本身不自动安装；安装前正常关闭 Revit，安装器保留旧安装备份并核对包清单及 DLL 哈希。Autodesk 程序集由本机提供，不打包分发。

Python 验证可安装 `requirements-validation.txt` 后运行：

```powershell
python -m unittest discover -s tests -p 'test_*.py'
```
