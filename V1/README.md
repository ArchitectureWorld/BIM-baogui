# H-IFC V1 · 0.4.4

`main` 为本版唯一开发主线。当前入口为 Revit 2020 中的 **H-IFC V1 → 模型属性管理 → 模型检查 / 属性管理**。

当前发布版本 **0.4.4**，程序集版本 **0.4.4.0**，文档更新于 **2026-10-19**。

## 日常操作

**1 人工确认阶段 → 2 模型类型 → 3 全面检查 → 4 写入 Revit**。

窗口全面读取当前模型，无需预选。模型可提供的面积、名称等自动填写；可直接修改右侧属性，修改草稿为红底，回读成功的人工值为橙底。阶段、类型、检查与草稿按模型暂存，重开后仍全面复检。

- 目前仅道路宽度要求手填；未填写时，左侧对应类目标红，写入回读并复检后更新。其他空值不新增强制手填红色提示。
- 设置新类目后刷新对应属性和自动值。统一写入时清空旧类目专属实例值，保留共用定义及类型值，失败整体回滚。
- 人防区域、消防分区、停车场和停车位支持原生 Revit 面积（Area），结合面积方案、名称与已有专用属性提供分类证据；未放置、未封闭及零面积另行报告。新增区域按实际适用，不据此增加必要构件。
- “地下楼层 / 基准”用于人工确认地下建筑楼层及项目标高基准，再生成地下层数和高度建议。确认记录按模型保存，全面检查时重新核对；已有手工值保留，差异单独说明。
- “选中构件赋属性”支持在 Revit 原生选择后人工指定业务类目、编辑并写入所选实例，写入后全面复检。
- 布尔参数提供“未填写 / 是 / 否”下拉。空的建筑基底按标高名预置首层为是、其余为否，已有明确值优先。
- 单体项目信息的建筑类型名称和建筑类别提供预置选项，建筑类别允许补充。预置不会清除已有的其他分类文字。
- 可写的已有值支持直接编辑和写入后再次修改；检查中、结果过期或只读/冲突时显示原因。

只检查模型与属性。材质、贴图、渲染和图例等辅助资源不参与检查。

## 构建与安装

```powershell
pwsh -File tools/Build.ps1
pwsh -File tools/Install-Revit2020.ps1
```

以上命令在 `V1/` 目录执行。构建需本机 Revit 2020 API、.NET SDK 和 .NET Framework 4.8 开发环境。当前输出为 `dist/Hifc.V1.Revit2020-0.4.4/`；安装脚本从该包复制到 `%APPDATA%/Autodesk/Revit/Addins/2020/Hifc.V1/`。安装前正常关闭 Revit；安装器保留旧安装备份，并核对所复制 DLL 的哈希。

Python 验证可安装 `requirements-validation.txt` 后运行：

```powershell
python -m unittest discover -s tests -p 'test_*.py'
```
