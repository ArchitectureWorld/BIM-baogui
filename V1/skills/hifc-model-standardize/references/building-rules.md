# 报规单体与地下区域规则

适用于用户已确认报规的单体；地上地下可以归属同一个 `IfcBuilding`。先用完整模型识别实际楼层与业务范围，再按当前插件契约写入。地下功能的受控模型证据不等同于所有客户地下项目或施工图验收。

## 识别与业务归属

综合墙、楼板、实际标高分布、幕墙、已有专用参数与图像判断建筑用途；没有独立门窗也可能是完整单体。普通楼板可列为建筑区域候选，但不能无条件计容。墙/窗需要人工分类或专用业务证据；仅有名称、普通尺寸或空参数绑定不构成业务分类。普通楼板类型文本“250”不能触发总平业务属性。

实际楼层与结构、地坪、屋面等辅助标高分开。首层/基底、地坪基准、地下层和顶层上边界按本项目确认；用户确认最高标高为屋面的约定只用于对应项目，不作为所有模型通则。未确定上边界时不造顶层高度。

## 建筑与区域的分类字段

分别维护：建筑类型名称、建筑类别、建筑用途名称（建筑级）与主功能/子功能（区域级）。以所选平台真实快照和已验证兼容值提供选项，主功能决定其子功能建议；未证实的“建筑类别 → 功能”关系不强行绑定。切换上级保留旧子项并明确提示，批量混合上级不猜统一子项。

2026-10-23 主会话技能审查中，用户再次确认当前 HBBIM 标准化将适用单体“民用建筑”统一写为“否”。已有“是”应进入明确修正预览并通过插件写入，记录为本轮兼容操作规则；不能漏填真实建筑用途。该操作要求不改写历史单字段实验的因果结论。人防参与独立核对，不由该值直接得出“不参与人防”的结论。

“建筑用途名称”缺失或按当前规则无效时明确标红。学校案例已证实在建筑级写入 `建筑用途名称＝中学` 能改变法规匹配，程序应原值写入和导出；不能把它写到区域子功能上冒充同一字段，也不能给全部新项目填中学。

自定义分类保留原文并标记平台识别待验证。统一可编辑下拉与自定义文字分类已在 0.4.18 候选完成生成模型验收，并进入 0.4.19 正式源码；运行前仍核对实际宿主版本，已加载版本不支持时报告具体限制，不能绕过写入校验、修改冻结字典或临时改 IFC 文本声称完成。

## 人工面积：实际写入是标准化完成条件

| 数值 | 处理口径 |
|---|---|
| 楼层面积 | 有效人工值优先；空值才根据已完整确认区域形成建议 |
| 建筑区域投影面积 | 与所属楼层的已确认申报总值同步；多区域按确认比例/范围分配并持久写入 |
| 项目建筑投影面积 | 独立保留人工值，用于建筑密度相关输入；不拿总建筑面积或多层面积之和替代 |
| 建筑总面积/计容结果 | 只在范围、系数、几何和重叠检查足够时汇总；人工值和差异另行记录 |
| 几何面积与 IFC 标准数量 | 用于几何及数量核验，与人工申报值分别保存，不相互覆盖 |

使用插件既有楼层—区域联动：完整确认的同层区域以有效原区域属性为比例；原属性空时采用可靠模型投影建议。按输入精度（至少两位小数）舍入，余差由较大区域承担，禁止负面积。一个整层总值不能重复填到每块区域。

需要分摊时，范围未确认齐全、来源无效或有已知重叠，先报告并定位；已分类区域面积已与楼层一致时，不因同层无关小楼板候选阻断原值导出。新的人工区域分配与楼层总值冲突时展示冲突，按用户最新明确选择解决。

楼层面积、区域分配、分类、范围或几何变化后，重新产生预览。使用全面管理的批量写入，将同次手工面积和自动联动一起提交、回读、保存；关闭重开后检查两层数据。直接导出时临时同步虽是插件兼容路径，不能作为本技能“已保存标准化 RVT”的完成证据。重复检查已同步数据应无新增写入。

学校五层 `1784.58 / 1638.73 / 1181.50 / 1181.50 / 669.29`、合计 `6455.60㎡`，以及首层 `1502.78 / 276.30 / 5.50㎡` 是用户确认的成功案例。综合楼/大门投影面积 `1784.58 / 37.6㎡` 也仅用于该次项目。参考软件采用首层主区域承载、其他区域面积/系数为 0 的方案须单独确认，不能悄悄替换比例分配。

## 地下与 Area 载体

| 业务 | Revit 载体 | IFC 载体 |
|---|---|---|
| 人防区域、消防分区、停车场、停车位 | Area | IfcSpace |
| 地下建筑区域 | 楼板 | IfcSlab |
| 实际地下楼层 | Level | IfcBuildingStorey |
| 地下层数、高度、地坪指标 | ProjectInformation | IfcBuilding |

非空专用业务参数优先于面积方案名称；多个专用证据冲突时待确认。IfcSpace 也可能来自房间，仅凭实体类型无法认定业务。未放置、未闭合、零面积 Area 逐项报告。

地下楼层按确认的实际楼层及地坪基准识别，不按负标高或名称直接计数；楼层 UniqueId 被替换/删除、重复标高或地坪变化时重验。地坪到最低确认层的高差可以形成地下高度建议，已有人工高度优先。每个楼层与区域均核对建筑归属，避免错误拆成两栋或丢层。
