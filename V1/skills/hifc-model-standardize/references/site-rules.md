# 报规总图规则

读取前先执行技能入口的来源、规范另存和全量盘点。以下是当前插件/案例可支持的业务规则，适用于已确认的总图对象；施工图要求与其他地区平台规则须另核。

## 分类、值与载体

| 业务 | 判断与填写 | 实际输出核对 |
|---|---|---|
| 规划净用地 | 确认业务范围；人工有效投影面积优先，模型面积用于建议和差异核对 | 适用载体及 `Pset_规划净用地信息属性集`，不重复统计同一净用地 |
| 净用地控制红线 | 归为规划控制线，且原生名/类型/业务证据符合已确认净用地红线身份时，名称、红线类型都写“净用地控制红线” | `IfcBuildingElementProxy` 与 `Pset_规划控制线信息属性集`；楼板载体由插件临时设置正确实体/预定义类型 |
| 道路边界线 | 先确认区内道路用途；仅消防道路的道路宽度必须人工给定，缺失标红 | 名称、区内道路类型、宽度及单位；不把名称“道路边界线”当作道路用途 |
| 道路红线 | 道路类型、红线宽度来自实际规划资料，缺项说明平台可能使用的默认值 | 与消防道路宽度是不同字段；不凭默认“主干路/15m”填入模型 |
| 绿地 | 报规总图中无冲突的绿化楼板可默认分类为绿地；读取实际几何建议，保留人工面积 | 类型、折算系数及面积落到正确实例，不把材质或植物族自动当绿地载体 |
| 停车位/停车场 | 用真实业务和边界确认相应 Area，区分两类及普通/充电等属性 | 有效 `Area → IfcSpace`，属性集直接关联正确空间，不能写在车模型上替代空间 |

名称“用地红线”本身不足以确认它究竟是净用地面积载体还是控制线。确认控制线身份后，“用地红线”“净用地规划控制红线”等旧业务值列入纠正预览，通过插件持久写成“净用地控制红线”；其他道路/建筑控制线不套用此值。

绿地类型缺失可能导致平台采用“集中绿地”并进入其他法规分支，应按实际用途补齐。学校案例的“附属绿地”、普通车位 11、充电车位 2、消防道路 4m 是该项目确认值，不是新项目默认。折算系数与运营属性按证据填写；普通数值不因空白自动补 0，布尔按共用政策处理并说明默认来源。

## 停车 Area 的空间判断与补建

先读可辨认的总平面、面积平面或局部三维，把连续车位组与 Area 真实闭合边界对应。按面积方案、所属标高和链接坐标区分重叠对象；插入点、包围框和 Area 数量仅是线索，不能直接代表停车数量。记录交叉、孔洞、重复、错层和边界外车位。

优先复用已有 Area。缺失且本轮标准化已授权补建时，在成果副本中按同标高、空间连续性和真实车位轮廓创建正确面积方案的平面、边界与 Area；不要圈入大片道路或空白区域。可将泛称 Area 命名为“停车位_<标高>_<两位序号>”。核对非零面积、闭合、车位组覆盖及无重叠重复。车位组推断数量与严格位于旧 Area 内的数量分开记录。

未放置、未封闭或零面积的 Area 报告模型缺口；任意房间或 IfcSpace 不会自动成为停车位。无新建权限的运行可给出可审阅边界建议，已授权部分继续执行。

## 绿地、道路的连通体

同一绿地/道路构件中不相交的实际几何体分别保有构件身份，每轮全量检查重验。合并实际相交实体后再用真实连通体判断；一个 Solid 也可能有多个分离体。孔洞不是独立构件，边界环数不等于连通体数。读取或布尔运算失败记未验证，包围框/网格片数不能替代。

在成果副本拆分时保留原生直线/圆弧、孔洞、类型、标高、偏移、阶段与有效业务值；核查宿主、组、连接、草图约束和外部标注依赖。先建并验证新构件，再在同一事务组移除旧载体；失败回滚，记录旧/新 UniqueId 对照。实例标记应唯一，无须为区分实例复制类型。

拆后每块重新取得自身几何建议，不把旧构件总面积复制到每个子件。原有人工申报总面积先保留在预览中，分配方式按已确认业务口径处理，不能借拆分静默覆盖人工值。验证每件一个连通体、几何并集/孔洞/曲线保持、面积体积守恒、无重复或新增相交。解析曲线面积与网格近似读数分别记录，同一算法前后比较并注明容差。

本条针对总图绿地/道路。单体建筑楼板的多块几何与业务计量按单体规则核对，不能直接复制拆分策略造成多份整层面积。

## 控制红线与净用地配对

“净用地控制红线”和“规划净用地”可为同一轮廓的不同标高实例，各自保留业务身份；不能因 XY 重合就删除其中一个或都算作净用地。

检查世界坐标下的水平外轮廓与位置一致，控制线按当前约定低于净用地，并核查实际厚度、实体相交和竖向净距。仅标高不同、包围框不相交或固定上移 0.5m 均不能替代实体核验。几何调整超出本轮已确认范围时先给出差异和方案，不自动统一升降。

人工坐标模板按 [数据与验收](data-and-validation.md) 采集。当前自动实体配对仅验证了单水平直线棱柱、单外环；曲线、多环/孔洞、斜面、多实体等须专项核对，不能报已通过。
