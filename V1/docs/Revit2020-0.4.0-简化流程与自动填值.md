## 日常操作

1. 人工确认阶段。
2. 自动识别或人工指定模型类型。
3. 全面检查当前模型，读取已有值，给出能够可靠生成的属性值。
4. 在右侧直接修改需要调整的值，点顶部“4 写入 Revit”。写入回读后自动全面复检；需要保存结果时另行保存 RVT。

自动建议显示“自动待写入”。人工修改暂存为红色；实际写入并回读成功的人工值显示橙色。多个构件、多个属性的修改可以累积后统一写入。双击清单构件或点击“定位所选”沿用原有定位方式。

参考覆盖、检查依据、变更明细和核验记录集中在底部默认折叠的“开发与核验信息”。

## 自动填写的来源

| 属性 | 本轮取值 |
|---|---|
| 投影面积 | 当前楼板或屋顶的实际顶面三角网投影到水平面，换算为 m²，保留孔洞；不使用包围盒面积 |
| 名称 | 当前 Revit 构件名称 |
| 规划净用地 / 版本 | 成功案例 `总图-属性写入-15.ifc`、STEP #983 的值 `1`，可人工调整 |
| 规划净用地 / 类型 | 本轮业务分类 `规划净用地` |
| 楼层名称、建筑名称 | 原有 Revit 标高名称、项目信息中的建筑名称 |

只有缺参数或未填写时才自动建议。已有值（包括 0、false）和有歧义、非法值不会被自动替换。未知业务系数、用途代码、消防高度等没有可靠来源的字段继续报告待补；无法取得可靠面积时明确报告原因，不填造假的 0，也不复制案例面积。

新建映射来源参数为文本，面积按平方米数值写入；已有面积类型参数换算回 Revit 内部单位后写入。完整 IFC 导出单位与原软件同模型对照继续单独验收。

## 暂存和复检

阶段、模型类型、上次检查、未写入修改、人工写入的最后一次值按模型保存到 `outputs/management-profiles/`。该记录只保存当前需要的状态和最后一次人工写入，不建立复杂历史系统。

重新打开窗口先恢复显示，再自动全量复检。缓存不能授权写入；当前文档、构件和参数载体身份、原值、来源签名仍必须匹配。发生冲突时保留修改并阻断写入，核对后重新填写；底部可清除未写入暂存。
