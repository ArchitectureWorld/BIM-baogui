## 常规验证用法

1. 使用 RVT 副本，按类目分批选择模型实例。
2. 点击“准备映射参数”，选择参考类目；程序不猜测业务数值、不修改几何。
3. 在 Revit 填写参考参数，例如净用地的 `规划净用地投影面积`、`规划净用地名称`，阳台的 `阳台投影面积` 等。
4. 点击“导出取数 JSON”留存来源证据。
5. 点击“工规导出验证”，使用新的 IFC 文件名。
6. 读取 `.receipt.json` 核对单次导出、临时事务回滚和源快照一致性；再用 IFC 检查器检查属性实际挂载关系。
7. 同一新模型再用参考软件正常入口导出，建立正式 A/B 基准。

当前选择式探针最多处理 5000 个构件。适配候选类别为楼板、墙、屋顶、门窗、房间、常规模型和楼梯段；已实测的类别仅为楼板。净用地样本在本轮导出为 IfcSlab，证明该参考配置允许的映射路径，不证明平台接受它作为用地几何载体。项目/楼栋/楼层元数据、分类、模板、单位、几何业务一致性及原始类型拼写问题仍待对照。18 个实测字段不能推算为全部 280 条通过。

## 设计与限制

- 原取值来源参数保留，205 个不同来源不按 113 个 IFC 属性名提前合并。
- GUID 由独立确定性规则生成；同一个输出属性在不同 Pset 上使用不同桥接参数。
- 未赋值、0、false 区分处理；同名来源歧义阻断。
- 原始 `Reall`、`Integerl` 保留；检查器不会将未知类型当作已通过。
- 实例/类型的当前选择策略是“有值的实例优先，再用类型”，仍需原软件实测对照。
- 导出实验使用单次 `Document.Export`，随后只读审计；临时参数、值和视图由导出事务回滚。
- 本机 2020 导出器会排除不可见参数，因此桥接定义在临时事务内可见且不允许用户修改，导出后回滚。
- 未使用的桥接参数保持未赋值；不能用空字符串清空，否则原生导出器会创建空属性并混挂无关 Pset。发现已有桥接值时阻断导出。
- 内部 Revit 参数 Pset 导出关闭，防止将 `__HIFCV1_` 临时名称写入 IFC；两个原生参数伪组未按普通业务 Pset 重建。
- 当前取数证据明确记录 Revit 原始存储值，未擅自套用官方单位纠正规则。
