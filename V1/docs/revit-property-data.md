# 历史 0.4.17-preview.2：复选框、报规表、人工红线资料

日期：2026-10-23。基线：main `550d736`。本页记录 0.4.17-preview.2 当时开发及安装事实；当前已安装版为 [0.4.18-preview.2](0.4.18-分类下拉与自定义输入.md)。该轮未修改客户原 RVT、原 Excel 或真实平台数据。

## 使用变化

- 管理窗口与手动工具的是否属性改为复选框。未填写按“否”；未填写的“建筑基底”沿用确认的基底楼层，否则按首层名称默认“是”，其余“否”。已有明确值（包括首层人工“否”）保留。编号及普通数值不因等于 0/1 而变成布尔。
- Revit 原生属性使用 `ParameterType.YesNo`。旧版本本插件创建的文字布尔，先显示迁移范围，再随“4 写入 Revit”整体迁移；捕获所有绑定类别及实例/类型值，失败连同本轮写入回滚。明细表、视图过滤器、全局参数引用、非本插件文字参数、同名歧义或非法值会阻止迁移，不删除引用。IFC 临时桥接继续使用 Text。
- 平台旧映射中，“建筑密度”同时用于总平布尔与场地数值；“间距审查、退让审查”同时用于楼梯段布尔与保温层文字。三项布尔分别使用独立来源“总平构件建筑密度、楼梯段间距审查、楼梯段退让审查”，IFC 属性名保持原样。合法旧布尔经整批预览和全类别核验后复制；原数值/文字定义、绑定和数据保留。未确认的其他载体、族来源、非法值或旧布尔引用会阻断，已有新复选框人工值优先。存在旧源而未写入新源时，导出明确要求先执行“4 写入”，不会将旧值当作空白默认否。
- “报规表导入”支持已有混合表，以及新模板中的一栋一表（多个工作表或文件）。选择当前表和对应楼栋，对照 Excel 与模型值；冲突默认不选、组合值不自动拆分、空格不清除模型数据。确认后进入原有属性草稿，点“4 写入 Revit”一起提交。
- 原始资料、未映射字段和文件哈希/工作表/单元格来源，随同一写入事务保存在 RVT 中。“模型已保存资料”可查看这些记录；它们不会自动变成官方 IFC 属性。仅资料的导入也可写入；未写入前随模型暂存并阻止直接导出。
- 楼层面积导入仍进入既有人工楼层面积与区域分配流程；不覆盖未被选用的人工面积，不把一个楼层总值重复写入多块区域。
- 表格及批量编辑明确使用 m² / m，原生 Area / Length 参数按 Revit 内部单位换算后写入和导出，不受项目显示为平方英尺或毫米影响。普通 Number、文字及编号不做长度缩放。长度、进深、窗台高和室内外高差沿用同一量纲政策。
- “红线资料”导入人工填写的坐标模板。先确认人工资料，再选择单位、内部/当前共享坐标及 X/Y 对应关系；不明时只能收集保存，不能显示比对通过。导出保留原模板表头，不以模型自身生成权威参考点。
- “规划净用地”与名称、红线类型均为“净用地控制红线”的载体配对，检查 XY 外轮廓及位置、实体厚度、布尔相交和竖向净距。它们是不同业务载体，不认作重复净用地。本功能只读几何，不自动升降构件。
- 手动工具写入后仍全面检查整个项目，结果与报告入口保留在当前手动窗口，不自动弹出或激活管理窗口。已有管理窗口可以更新结果。

## 首批边界

目前红线实体核对支持单一水平直线棱柱、单外环。曲面、曲线、多环/孔洞、网格、斜面、多实体以及未知几何明确报告待处理，不会误报通过。坐标框架选择只说明与 Revit 的对应关系，不证明测绘坐标系本身正确。平台上传坐标和服务器红线审查未接入本轮写操作。

已有学校 Excel 将“综合楼/大门”和“6455.60/37.6”写在同一表内，不作为可自动拆分的两个单体；需要分别整理或明确对应。原表中的建筑密度、绿地率、容积率与已填面积比例存在差异，导入会报告核对，不自行改成另一个统计口径。不会因此把所有 Excel 单元格变为插件必填。

原生复选框迁移会改变项目参数定义，建议首次在模型副本操作。遇到外部软件或族参数来源，按提示先统一定义；插件不会为了完成迁移而静默删掉这些来源。

## 复现入口

```powershell
pwsh -File V1/tools/Build.ps1
dotnet build V1/tests/Hifc.Native.Tests -c Release
pwsh -File V1/tests/Hifc.Native.Tests/Run-PropertyDataAcceptance.ps1
# 候选加载后立即恢复正式清单；正式 DLL 从未替换：
pwsh -File V1/tests/Hifc.Native.Tests/Run-PropertyDataAcceptance.ps1 -RestoreRun <本轮验证目录>
# 宿主完成后，用带 ifcopenshell 的 Python 3.12 独立核验：
python V1/tests/Hifc.Native.Tests/Verify-PropertyDataExport.py <本轮验证目录>
```

宿主只生成验证 RVT；临时清单带哈希检查与恢复入口。若正式 Revit 在运行，脚本拒绝启动。构建不会自动安装预览包。
