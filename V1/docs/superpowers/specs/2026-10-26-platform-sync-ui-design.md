# 平台同步窗口统一界面方案

日期：2026-10-26。状态：用户已确认“按此方案统一”。本次为现有候选上传窗口的界面整理。

## 目标与依据

平台同步窗口应与“模型检查与属性管理”、导出命名等现有窗口保持一致。现有 `Management/LiquidGlassTheme.cs` 已提供浅蓝渐变背景、深蓝标题、圆角按钮/卡片、蓝色主操作、统一下拉与表格。当前 PlatformSyncWindow 未使用这套主题，并将 Node/程序/配置路径放在最上方，用户难以分清设置与日常操作。

## 方案选择

- **推荐：复用主题并整理布局。** 保持独立窗口及既有同步步骤，将日常操作集中、技术设置折叠；同时统一样式和信息层级。
- 仅套控件颜色：改动较少，但技术设置占据主视区、按钮和信息分散的问题仍存在，不推荐。

本次沿用原生 WPF 与现有主题，不引入新 UI 框架或单独的配色体系。

## 推荐布局

1. **顶部标题与摘要。** 与模型管理窗口使用相同标题层级及蓝色装饰；显示当前项目、RVT/本次 IFC，以及平台可编辑状态。文件名完整可查看。
2. **编号操作区。** “1 读取平台 → 2 确认对应模型 → 3 预览同步 → 4 开始同步”。沿用现有读取、绑定、预览、二次确认与后台启动行为；“刷新状态”作为次要操作。
3. **中部内容。** 左侧卡片展示项目及当前 IFC；右侧卡片选择平台模型、展示已确认对应关系和将替换的文件。统一标签宽度、输入框高度和卡片间距。
4. **同步状态。** 下方卡片列出任务状态、转换/计算信息及法规审查。计算完成与法规通过继续分别显示；默认以用户能理解的名称和状态为主，内部任务 ID 放入详情。
5. **底部设置与详情。** 程序位置、配置文件、内部标识和诊断说明集中在“平台设置与诊断”折叠区。已有有效配置时默认收起；首次缺配置或配置失效时展开并说明缺项。

## 视觉和状态

直接调用同一套 LiquidGlassTheme 的 Apply、Title、Card、Primary、Combo、Table 等能力。字体、字号、按钮高度、圆角、间距与现有窗口保持一致，不另外复制主题代码。

主操作使用蓝色；普通操作使用浅色。未就绪操作禁用并就地说明原因；审核中明确显示“当前审核中，无法替换模型”。失败/缺失用红色，进行中用蓝色，完成用绿色，状态始终同时显示文字。

适配窗口缩放和常见 Windows DPI，长文件名不挤压按钮；列表区域可滚动，主操作和关键状态容易找到。

## 实施与验证范围

主要修改 PlatformSyncWindow 的展示与交互排布，复用现有主题。仅在独立预览项目需要时补入共享主题文件链接；不修改同步引擎、模型属性或 IFC 导出规则。

完成后用独立 WPF 窗口展示未配置、已绑定/已预览、审核中、同步中和失败状态，检查常规及窄窗口截图，执行相关界面回归。候选仍待真实平台可编辑项目验收；本次界面修改不自动安装正式插件或发起平台替换。
