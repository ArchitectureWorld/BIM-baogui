## 已实现

- Revit 完整导出成功后登记本次 export_id；同步时冻结 IFC 和回执，C# 与独立程序分别核验哈希。普通导出仍可单独使用。
- 独立 WPF “平台设置、读取平台模型、确认绑定、同步本次 IFC（预览）、同步状态”；模型从完整清单选择，绑定不依赖导出日期或 V1/V2 名称。
- TypeScript / Playwright / SQLite 独立程序；专用浏览器、Windows DPAPI 凭据、单项目锁、写前意图、备份校验、未知结果核对及显式回滚。

## 使用与边界

独立体验运行 [Start-LocalDemo.ps1](../platform-sync/Start-LocalDemo.ps1)，不需要启动 Revit。配置及 CLI 用法见 [独立程序说明](../platform-sync/README.md)。当前已安装试用版包含平台同步预览入口，下次启动 Revit 可见；真实平台写操作仍未开放。

真实平台适配器本轮只读：缺少项目/场景/模型版本证据时不推测内部 ID。非 GET/HEAD/OPTIONS 暂被阻止，因此平台自身的只读 POST 也可能无法工作。接下来需要核验真实平台身份、旧 IFC 下载及代次对应、本次转换/计算关联与断网恢复，之后才能另行验收实际写入。

当前本地锁不能排除另一台电脑同时修改平台；每次写入前重核代次只缩小冲突窗口，不能保证跨机器排他。回滚仅支持已验证完成的本地演练任务；失败/超时任务先核对，保留锁与证据。监听、批量、无人值守及真实平台写入均未启用。

安装工具默认指向当前已验收试用包 `0.4.19-preview.1`；`Build.ps1` 按开发版本输出包但不自动安装，旧安装完整备份保留。
