更新：2026-10-23。源码版本 `0.4.17-preview.1`，独立程序 `0.1.0`；稳定安装仍使用已确认的 `0.4.16`。

本轮按用户确认的交接方案开发，并获准直接合入本地 `main`。当前模型、原 RVT 和真实平台模型没有因预开发而改动。稳定版 0.4.16 的安装另获用户授权，安装 DLL 版本与既有打包哈希一致；本次未启动 Revit，不能称为宿主加载验证。

## 已实现

- Revit 完整导出成功后登记本次 export_id；同步时冻结 IFC 和回执，C# 与独立程序分别核验哈希。普通导出仍可单独使用。

## 使用与边界

独立体验运行 [Start-LocalDemo.ps1](../platform-sync/Start-LocalDemo.ps1)，不需要启动 Revit。配置及 CLI 用法见 [独立程序说明](../platform-sync/README.md)。当前 Revit 中安装的 0.4.16 不会出现新平台入口；只有未来明确安装预览版后，才能在宿主使用这些新入口。

真实平台适配器本轮只读：缺少项目/场景/模型版本证据时不推测内部 ID。非 GET/HEAD/OPTIONS 暂被阻止，因此平台自身的只读 POST 也可能无法工作。接下来需要核验真实平台身份、旧 IFC 下载及代次对应、本次转换/计算关联与断网恢复，之后才能另行验收实际写入。

当前本地锁不能排除另一台电脑同时修改平台；每次写入前重核代次只缩小冲突窗口，不能保证跨机器排他。回滚仅支持已验证完成的本地演练任务；失败/超时任务先核对，保留锁与证据。监听、批量、无人值守及真实平台写入均未启用。

稳定版安装工具继续固定指向 0.4.16；`Build.ps1` 按开发版本输出独立预览包，不覆盖稳定包。
