# 模型检查与属性管理 · 已确认设计

2026-10-14 用户确认：采用可与 Revit 同时操作的独立管理窗口。打开即扫描当前项目，无需预先选中构件；本会话顺序实现，不启用子 Agent。

## 工作流与页面

主入口“模型检查 / 属性管理”。非模态 WPF 窗口与 Revit 模型同时操作。顶部显示必要模型、类目确认、映射字段填写情况；左侧按楼栋/楼层/类目浏览；中部为可筛选、可多选的构件清单；右侧查看来源与缺失属性，并支持编辑；底部提供预览、写入和复检。

当前文档为默认范围，链接模型不混入可写范围。扫描候选类别沿用已实现的映射适配范围，其他载体明确显示本版未支持。楼栋未提供时标为“未指定楼栋”，不推测楼栋归属。扫描只读取身份和相关参数，分批运行，展示进度并允许取消；取消/失败的部分结果不能显示为完整扫描。

## 判断口径

参考工规契约只定义映射，不定义项目中每种模型是否必须存在。用户在窗口内确认本次必要模型清单，设置保存在 V1 的项目检查配置中。未确认清单显示待确认；不能将全部 43 个业务属性集自动视为必需模型。

“缺模型”“存在候选但未分类”“缺参数”“参数未填写”“值非法/有歧义”“载体未支持”分别表达。必要要素有未分类候选时显示待分类，而非断言物理模型不存在。完成度分别统计，不把已有字段填写率 100% 当成整项目完成。0/false 视为有效值；异常原始类型保持待核验。

可按界面筛选范围批量分类与补充参数，可在界面多选构件批量修改同一个来源属性。源参数名、固定 GUID 及已验证的导出桥接策略保持。业务值不自动猜测；类型来源字段在本版只读，避免批量改类型影响范围外构件。

## Revit 边界与写入

WPF 不直接读写 Revit API。命令打开窗口并创建 ExternalEvent，扫描读取在允许的 API 上下文分批执行；窗口只持有普通 DTO。窗口固定对应打开时的文档，切换文档、关闭文档、预览后模型变化都会阻断写入。

每次修改先生成包含构件身份、旧值、来源及新值的预览；执行时重新比较目标快照。事务执行，回读验证；失败回滚。写入后自动扫描。保留记录及已验证的单次原生 IFC 导出，原软件 A/B、官方补齐仍按原阶段安排。

## 验收

- 空 Revit 选择集可打开窗口并扫描项目。
- 能分辨缺模型、待分类、缺参数/缺值，缺模型时整体不能显示完成。
- 单击指标/树节点筛选；双击构件在 Revit 定位；面板可编辑实例字段、批量分类、预览并写入。
- 模型变更后的旧预览被拒绝；失败不留下部分写入；0/false 不丢失。
- 大批构件扫描有进度及取消，窗口适配最小尺寸；模板/导出回执测试不冒充真实模型或平台验收。
