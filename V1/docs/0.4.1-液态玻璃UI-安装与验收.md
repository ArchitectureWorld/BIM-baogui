# H-IFC V1 · 0.4.1 原生 WPF 浅色玻璃 UI

## 范围和边界

以 `codex/hifc-v1-0.3.2` 的 `V1` 为源分支，仅调整 H-IFC 模型管理窗口的显示、布局和独立 UI 验收配置。

- 保留既有的四步工作流：人工确认阶段 → 模型类型 → 全面检查 → 写入 Revit。
- 保留原有模型分类、构件定位、检索与筛选、属性单元格编辑、暂存冲突、二次复检、分类修正、HTML 报告与调试面板。
- 保留 `ManagerController` / `ExternalEvent` / 原生 Revit API 读取和写入；不改变任何规则、映射数据或 IFC 输出内容。
- 界面通过无第三方依赖的 WPF 渐变半透明面板、细描边与阴影模拟液态玻璃层次；**不声称具有 Windows 系统级真实背景折射或 Acrylic 模糊**。
- 没有引入 WebView2、依赖联网的前端运行时或 macOS 仿制标题栏。

## 安装到 Revit 2020

1. 下载 UI 分支 ZIP 并解压完整仓库，勿仅复制 `ManagerWindow.cs`。
2. 在安装了 Revit 2020 的 Windows PC 上确保具备 .NET SDK 和 .NET Framework 4.8 目标框架开发包。
3. **正常关闭 Revit 2020**；请事先保存打开的项目。
4. 双击 `V1/安装并体验UI.cmd`。此入口先运行核心与 WPF 测试，再编译并安装插件。
5. 重新打开 Revit 2020，在 **H-IFC V1 → 模型属性管理 → 模型检查 / 属性管理** 打开窗口验证。

实际文件安装在 `%APPDATA%\Autodesk\Revit\Addins\2020\Hifc.V1`，`Hifc.V1.addin` 位于同级目录。安装器保留旧版的时间戳备份和哈希回执，并且不会结束 Revit 进程或改动其它插件。

仅编译不安装可在 PowerShell 运行 `./tools/BuildAndInstall-GlassUI.ps1 -BuildOnly`；编译结果存于 `V1/dist/Hifc.V1.Revit2020-0.4.1/`。

## 控件一致性规范（2026-10-15 UI 第二轮）

工具条的可点击控件使用单一规格：**36 DIP 高 / 10 DIP 圆角 / 12 DIP 字体 / 8 DIP 水平间距**。普通操作按钮最小宽度 96 DIP；动态写入说明可以增加宽度，但绝不改变高度。禁用、选中、主次按钮仅调整颜色及透明度。

统一范围包括：顶部阶段与模型类型、全面检查/写入/取消，列表的全部筛选/全选/定位、搜索栏外轮廓、右侧业务分类及提交、底部保存报告。只读的“显示 X / 全量 Y”采用同高但不可点击的轻量状态标签。具有两行说明的模型分类项、紧凑数据表格行以及可展开的核验指标卡，仍按各自信息密度调整行高，不错误地收缩为单行工具按钮。

通过 Windows GitHub Actions 验证：参考核心 **80/80**；WPF 独立真实窗口 + 模拟数据/模拟 Revit Adapter **43/43**；补充检查包括控件实际渲染高度、圆角、下拉菜单打开与关闭、三栏不重叠、自动值与暂存写入原有流程。截图由测试程序真正渲染，不是概念效果图；Revit 2020 实机验证仍需在本机安装后完成。

## 本轮 UI 验收清单

- 宽度 1430 和最小宽度 1080 两种窗口下，无布局截断导致的功能不可用。
- 左侧业务类别筛选、中央表格搜索/全选/定位和右侧属性编辑可以连续工作。
- 对原模型数值的自动读取及“待写入”（红）/“已手工写入”（橙）语义保持不变。
- 点击写入前，编辑检查和冲突拦截仍生效；关闭并重新打开后，草稿状态恢复、复检要求维持。
- 同一原始 RVT 与 0.4.0 版本比较，不存在因 UI 重构引起的 IFC/映射规则差异。
- 独立 WPF 测试生成截图仅包含模拟数据；不能代替 Revit 2020 真实模型验收。

若安装和编译失败，请保留 PowerShell 错误文本，禁止通过跳过失败测试强行覆盖正在使用的插件。
