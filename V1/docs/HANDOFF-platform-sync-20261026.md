## 模块与入口

| 位置（相对 V1） | 职责 |
|---|---|
| platform-sync/src/engine.ts、store.ts | 冻结交接、绑定、备份、非目标保护、状态机、锁与恢复 |
| 同目录 real-contract.ts | 真实项目/模型响应解析、代次指纹、下载地址限制、审核状态 |
| real-browser.ts | 独立 Edge、正常网页操作、范围受限请求、真实字节校验 |
| real-evidence.ts、real-calculation.ts | 有界持久证据、上传关联、计算输入及请求时序 |
| worker.ts、cli.ts | 后台启动、持久状态、只读恢复及显式 apply |
| src/Hifc.Revit/PlatformSync/PlatformSyncClient.cs | 无 shell CLI 调用；后台任务不受窗口等待时限影响 |
| 同目录 PlatformSyncWindow.cs | 读取、绑定、预览、“确认并开始同步”和状态 |

Node 24+、TypeScript、Playwright，Windows 使用独立 Edge profile，运行不需要 LLM。`npm test` 执行同步回归；`Start-LocalDemo.ps1` 提供独立 WPF 本地演练。接口见 [CONTRACT](../platform-sync/CONTRACT.md)，入口见 [README](../platform-sync/README.md)。

普通 IFC 导出独立保留。只有 NativeExportService 完整成功回执和冻结副本可入队，不以 IFC 文件存在判断成功。真实模式需显式 adapter=real 和 --apply；当前真实配置保持 real-readonly。

独立复核的三项问题已添加失败用例并集中修复：

1. 提交成功而 Run 尚未记录新模型时，恢复选择已核对的提交证据，再下载新模型核验哈希。
2. 排除延迟历史响应：查询须发于本次受理后，完成查询须发于已观察到处理中之后；证据存储也要求处理中记录。
