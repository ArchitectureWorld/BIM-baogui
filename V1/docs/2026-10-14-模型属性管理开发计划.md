# 模型属性管理 Implementation Plan

> **For agentic workers:** 使用 superpowers:executing-plans 在当前会话顺序实现。用户已确认独立管理窗口及工作流；不启用子 Agent，不创建额外项目或分支。

**Goal:** 将 V1 主入口改为无需预选择构件的可视化项目检查与属性管理窗口。

**Architecture:** Core 负责字段状态/必要模型/完成度；Revit 服务负责分批读取和带快照验证的事务写入；WPF 通过 ExternalEvent 请求服务，呈现 DTO。

**Tech Stack:** Revit 2020、net48、WPF、C#；沿用本机 SDK 7 与已有 IfcOpenShell 核验。

**Spec:** [已确认设计](2026-10-14-模型属性管理设计.md)。

## Global Constraints

- 只在 V1 开发，保留冻结参考契约，官方补齐延后。
- 不修改用户打开的模型进行测试；新版安装要求 Revit 正常退出。
- 只读扫描不启动写事务；API 调用只在 Revit 上下文执行。
- 参数赋值需可见预览、身份及旧值校验、事务与回读。
