# 0.4.5 绿化默认分类与规划控制线

版本 **0.4.5**，程序集 **0.4.5.0**，适用 **Revit 2020**，更新于 **2026-10-20**。已安装并完成下述模型副本验证。本轮修正报规总图的绿化分类、规划控制线，并将正式 IFC 导出改为当前项目全量导出。

## 绿化楼板的默认分类

报规总图中，名称或类型名含“绿化”、载体为 IfcSlab、没有已声明业务类目且没有其他冲突候选时，默认按“绿地”生成补齐项，读取当前构件的实际水平投影面积。点击“4 写入 Revit”后提交分类和属性，再全面复检。

已有人工分类和有效属性值保留。其他载体的“绿化”仍显示载体核对原因；此规则不扩展到材质、植物族或单体建筑模型。

## 手动指定规划控制线

“模型检查 / 属性管理”和“选中构件赋属性”两个入口均支持将楼板手动指定为“规划控制线”。符合条件的楼板与常规模型可共同选择该类目，属性写入限定相应实例。

参考成功案例的规划控制线使用 IfcBuildingElementProxy。楼板在检查和属性读取中按该业务实体处理；原生 IFC 导出事务临时设置相应实例的 IfcExportAs 和 IfcExportType，将预定义类型设为 NOTDEFINED，避免沿用楼板的 FLOOR 枚举。导出完成后整体回滚并核对来源参数，不永久改变楼板的导出参数或共享类型。无法安全设置实例导出参数时明确报错。

手动改回绿地时清理旧控制线专属值，保留共用值和共享类型，重新读取楼板的实际几何面积；后续导出恢复为 IfcSlab。名称为“用地红线”不作为自动指定规划控制线的依据，具体用途由人工选择。

构建、安装、实际 IFC 与属性完整度分别记录，见 [0.4.5 机器可读摘要](../validation/0.4.5-validation.json)。

- 构建过程曾出现一次既有 `native_dropdown_selection_still_operates` 断言失败；未修改该用例，完整复跑通过。两次输出均保留在本机验证日志。
- 学校总图副本首轮 26 项宿主检查通过，但独立 IFC 核验发现 Proxy 沿用了楼板的 FLOOR 枚举。已补充临时 IfcExportType=NOTDEFINED；修正版混合、仅控制线及改回绿地三组 IFC 分别核验 6、3、3 项属性，schema 错误均为零。Proxy 实例及类型均为 NOTDEFINED，改回绿地恢复 IfcSlab。首轮失败文件与审计记录继续保留。
- 最新副本完成 35 项 Revit 宿主检查，覆盖实际写入、原值回读、未选实例及共享类型保护、全量复检、保存重开和导出后回滚。
- 全项目 IFC 实际包含 24 个 IfcSlab、1 个 IfcBuildingElementProxy、2 个 IfcSpace。未分类楼板的投影面积为 6㎡，自动归类绿地为 50㎡，停车 Area 为 12.5㎡，未分类 Area 为 6㎡，均从 IFC 几何独立复算吻合；停车属性集只挂在相应 IfcSpace。未闭合 Area 在回执报告，没有伪造空间实体。
- 全项目已输出的 41 项映射属性核验通过，schema 错误为零。另有 40 项来源为空（18 组绿地类型及折算系数、3 项道路相关值、1 项公建车位），均未伪造输出。保留严格完整度核验的未通过状态，不将这些空值升级为新必填项，也不宣称所有属性已经齐全。
- 最新构建、包、安装及实际加载的 DLL 哈希一致；原始 RVT 哈希不变，测试 Revit 正常退出，所属临时验收清单已移除。结果仅覆盖上述副本及构造载体，不等于原软件同模型 A/B 或正式平台验收。

## 默认导出当前项目

功能区入口改为 **H-IFC V1 → 模型属性管理 → 导出项目 IFC**。直接选择保存路径即可，不要求选中构件，也不使用管理窗口筛选、当前视图隐藏或剖切框限定导出。

- 几何由 Revit 原生 IFC 全文档路径输出，未分类的普通模型仍参与导出；不再将“已分类载体”当作全部模型。
- 面积（Area）随空间对象一并参与导出；有效对象输出为 IfcSpace。未放置、未闭合或零面积对象在回执列明构件 ID 和原因，不能伪造有效空间。
- 已分类且映射匹配的载体临时物化 HIFC 属性；已有建筑、楼层属性一并处理。不强制普通构件分类，也不新增必填项。
- 不支持或冲突的业务映射在回执记录，避免套用错误的 HIFC 属性集；几何仍由原生导出器处理。无法安全隔离同名属性回退来源时继续明确阻止误导出。
- 范围是当前项目文档；其他已打开项目和链接源文档不自动并入。原生 IFC 的阶段、设计选项及明确不导出设置仍按 Revit 原生规则处理。
- 每个 IFC 只调用一次 Document.Export，不做 IFC 后处理。临时参数、绑定及导出覆盖整体回滚，逐载体哈希核对 HIFC 取值来源。

“选中构件赋属性”仍用于人工分类和定向写入；局部 IFC 导出只保留在开发验收调用中。回执版本为 `hifc.native-export-receipt/1.4`，记录全项目范围、Area 数、映射载体数、未覆盖项及控制线临时实体覆盖。

## 构建与安装

构建包为 `V1/dist/Hifc.V1.Revit2020-0.4.5/`。从仓库根目录运行：

```powershell
pwsh -File V1/tools/Build.ps1
pwsh -File V1/tools/Install-Revit2020.ps1
```

安装前正常关闭 Revit。其余日常操作与适用范围见 [V1 使用说明](../README.md)；仅道路宽度继续要求手填，不新增必填模型或属性规则。
