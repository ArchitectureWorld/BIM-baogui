# 0.4.10 消防道路与导出核对

开发日期：2026-10-21～22。源码及构建包版本 `0.4.10` / 程序集 `0.4.10.0`；正式安装为 `0.4.10`。本轮未提交或推送 Git。

## 本轮行为

- 仅道路边界线属性中的“区内道路类型＝消防道路”触发道路宽度手填提示；普通道路、用途未确定的道路、道路红线不套用该要求。用途更改后重新检查，提示按实际写入值更新。
- 右侧属性、全面检查及导出核对共用平台缺项说明。绿地类型、用途、停车配置、红线宽度等缺失时，说明可能采用的默认值或计算分支。零、“否”是已有值，默认值不写入模型；同名参数歧义单独报告。
- “计算设置”的共用输入增加公建车位、红线宽度，沿用只补空值的规则；需要覆盖已有值时，在所选构件属性中明确修改。
- 用户导出入口显示可定位的核对表，区分模型当前面积和本次 IFC 面积。可返回修改，也可确认继续导出；提示不等同于平台通过。自动验收入口仍支持无界面导出。
- 管理窗口内的手工草稿先写入 Revit；即使关闭管理窗口，暂存草稿也会拦住用户导出入口，避免以旧值生成 IFC。导出不自动保存 RVT。
- 另存为后暂存记录跟随新模型路径；有草稿而暂存写入失败时，窗口保持打开。面积来源冲突、楼层区域不完整时仍显示核对和定位，无法确定的面积不会获准导出。

## 人工面积口径

沿用已经通过平台计算的 0.4.9 规则：有效楼层面积优先，完整的同层建筑区域按原区域面积比例分摊，分摊合计与楼层总值一致。若只在 Revit 修改了楼层面积，直接导出会使用临时同步值并回滚；“4 写入 Revit”则保存对应区域值。预览、写入与导出共用规则。

五层实测目标依次为 **1784.58、1638.73、1181.50、1181.50、669.29㎡**，总计 **6455.60㎡**。F1 三块区域为 **1502.78、276.30、5.50㎡**。不以平台几何复算覆盖人工申报面积，不将建筑总面积、楼层面积、投影面积混成一个字段；几何和计算系数保留。
