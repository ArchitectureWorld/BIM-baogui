| 能力状态 | 分类可编辑下拉已进入 0.4.19 主线，移除“仍在开发”的当前状态；保留候选原生测试与正式新哈希未重复宿主测试的区别。 |
| 民用建筑规则冲突 | 主会话明确询问此前用途实验结论与技能规则的冲突，用户再次回答“侧栏已有新结论，需要统一改为否”。保留适用单体统一写否的最新操作规则，通过预览与插件写入执行；不改写历史单变量实验因果，人防仍独立核对。 |
| 人工数据和个案 | 保留人工面积优先、楼层与区域持久写入、项目投影独立、布尔空值与基底例外。学校的面积/数量/屋面/高度调整均标明项目范围。 |
| 接手边界 | 完整导出与局部开发验收分开；阶段/草稿旁路与 RVT 参数/资料存储分开；未保存内容必须纳入正确的另存成果，文件存在不等于成功。 |
