## 功能与使用

用户确认的入口是平台顶部“综合报告”。本次同步与计算核验成功后，程序自动下载平台原生 PDF，生成同名 UTF-8 BOM TXT，并在窗口独立显示报告状态。PDF 不经重新排版或内容加工。平台原生封面标题为“规划方案审查报告”，这是“综合报告”入口返回的原文件。

命名为 `DOC_平台项目名称_YYYYMMDD_V1.pdf` 和同名 `.txt`。日期按本机日期，同日新归档递增版本，次日从 V1 开始；已有 PDF 或 TXT 都占用该版本。重试恢复原配对文件，不重复生成版本，不覆盖人工修改。

保存目录取成功任务的来源 RVT 路径，不随当前 Revit 文档切换。TXT 记录本次实际计算的全部 IFC 模型名称、模型 ID/代次、计算完成时间、报告生成时间和下载时间。窗口提供“下载／重试”“打开目录”；技术配置继续收在底部折叠区。

报告下载失败不重新上传或计算，不改变模型同步成功状态。“计算完成”“法规审查”“综合报告”分别显示。法规是否通过必须另取证，下载成功不能替代该结论。

## 实现入口

| 文件（相对 V1） | 职责 |
|---|---|
| platform-sync/src/report.ts | 任务资格、独立报告状态、命名、冻结、发布意图、配对恢复和哈希校验 |
| platform-sync/src/real-report.ts | 正常综合报告入口、项目/计算/模型归属、PDF 来源与时间校验 |
| platform-sync/src/real-browser.ts | 同源限定报告请求、计算读取、报告期间禁止重复模型写入 |
| platform-sync/src/real-evidence.ts | 已核验完成时间保持稳定，拒绝用后续不同结果覆盖原证据 |
| platform-sync/src/cli.ts、worker.ts | 成功后自动调用；report-start/report；进程互斥与启动失败恢复 |
| src/Hifc.Revit/PlatformSync/PlatformSyncClient.cs | 报告 DTO、独立命令与任务可重试条件 |
| 同目录 PlatformSyncWindow.cs、PlatformSyncWindow.Layout.cs | 综合报告卡片、状态、重试与打开目录 |

生成前后重新核对平台当前项目、结果记录哈希、全部模型身份与代次。TXT 中的模型来自持久化计算输入 `calculation_models`。报告 POST 仅允许当前项目、规划类型及已核对的全部字段一次；下载只接受当前项目综合报告目录中的原生 PDF。PDF 生成时间不得早于本次计算。

下载后先在内部冻结 PDF/TXT 并持久化发布意图，再以不覆盖方式发布每个文件。单边中断可用冻结内容补齐，无需重新连接平台；交付内容被修改时停止。未完成下载的持久状态仍可点重试，实际活跃 worker 与项目锁拦截重复操作。原同步 worker 自动下载期间，不另起报告 worker。

## 后续边界

正式发布及候选窗口在 Revit 宿主中启动报告后台任务尚未进行。真实报告下载和本地连续自动链路已分别验证，不等于重新执行一次无人工介入的真实上传到报告全过程。

真实断网全阶段恢复、异机并发仍需专项验收，本地锁不是分布式锁。旧计算或来源 RVT 移动导致证据不足时，明确阻断，不能静默猜测报告归属或目标目录。

低优先级启动恢复边界：worker 元数据若在写入期间因机器中断损坏成无效 JSON，目前需人工核对后恢复，不能称任意文件损坏都可自动恢复。正常启动失败、无 PID 遗留占位、下载后发布中断已覆盖。
