## 使用与范围

在原有“计算设置”中选择规则配置。本次加入 **保康县 420626 / SUBTYPE=0 / 报规 / 2026-10-20 快照**；未选择时保持原案例参考模式。选择随项目暂存，切换配置保留已有值和草稿。

- 右侧属性和项目共用值使用该快照的真实选项。主功能改变后，子功能选项同步变化；已有不匹配文字保留并提示核对。
- 缺口按已确认适用的类目核对，包括字段尚不存在的情况。平台显示必填不表示项目必须有全部类目，也不表示每项必须手填。只有道路宽度强制人工填写。
- 普通楼板类型参数（例如文本 `250`）不再触发总平业务集。只有明确分类的总平构件才输出该集；原类型参数保留。
- 所选配置下，雨篷使用平台拼写并保留旧来源参数；室内停车场以 Revit Area / IfcSpace 表达；窗使用实例标高、底高度、宽高，单位转换和实例作用范围分别验证。
- 墙、窗只凭人工分类或专用业务证据进入业务类目。普通墙、幕墙及仅名称叫“女儿墙”的对象保留几何盘点，不因名称自动创建业务字段。“是否为女儿墙”的非空原值可提供证据，0/false 继续有效；泛用高度和空参数绑定不作为依据。
- 辅助标高保留原生模型层级，但不冒充实际楼层计算输入。本地建筑面积、计算标高、楼层面积可作辅助结果，不作为此快照的必需输入。
- 不读取平台默认值替模型填入未知用途、系数和最高层上边界。已有 0、否及人工值继续保留；非法非空值在写入/导出前提示，不静默替换。
