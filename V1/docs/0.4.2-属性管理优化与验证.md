# 0.4.2 属性管理优化

本轮按用户确认的六项需求开发，继续使用报规成功案例 01 的检查范围。没有增加官方必需模型、材质或渲染资源规则。

操作仍为“1 人工确认阶段 → 2 模型类型 → 3 全面检查 → 4 写入 Revit”。

- 目前只对“道路宽度未填写”在左侧对应分类标红，并显示待手填数量。右侧草稿不消除红色，写入回读并全面复检后更新。其他空值、属性异常及未找到的参考项保留实际状态，不因此新增强制手填规则或左侧红色提示。
- 设置新分类后，右侧立即显示新分类的属性和模型自动值。确认写入时，在同一事务组内清空旧分类专属实例值，并写入新分类与属性。保留共用参数定义和类型值。不能安全清空的 Revit 数值参数会阻止该次分类写入，不以零代替空值。
- 全量扫描纳入原生 Revit“面积（Area）”。结合面积方案、名称和已有专用参数识别停车位，使用 IfcSpace 对应的停车位属性集。未放置、未封闭和零面积对象列入模型补充报告。
- 布尔属性使用“未填写 / 是 / 否”下拉。建筑基底在没有现值时按标高名称预置：一层、首层、1层、1F、F1 为“是”，其余为“否”。现有明确值优先。名称推断结果仍可人工调整。
- 单体项目信息中的“建筑类型名称”“建筑类别”继续列入必填检查。类型名称预置住宅、公建、中小学等、幼儿园等、厂房、办公、生活服务设施、其它设施；类别预置住宅、商业、商住、配套车库、中小学，并允许补充如工业厂房等类别。使用文字值，没有编造编码。
- 可写的已有值支持单击进入编辑，写入后可再次编辑。检查中、结果过期、来源冲突或只读时，在属性状态和提示中说明原因。

草稿红底、已手工写入橙底及阶段/模型类型暂存继续保留。恢复暂存后仍全面复检，不能依据缓存直接写入。
