# Revit 2020 · H-IFC V1 0.2.1 扫描修复

0.2.0 的管理窗口能打开，但在真实 RVT 中没有生成扫描结果。原生诊断确认同一 Revit 项目跨 API 回调返回不同的托管包装对象，引用比较为 false，而 Document.Equals 为 true；生产 Guard 因此错判为其他项目并阻断扫描。

0.2.1 将当前文档保护和 DocumentChanged 回调的身份比较修正为 Document.Equals。项目关闭或切换仍须阻断；当前项目变化应使结果和预览过期。

修复前测试已在真实总图中观察失败，脚本为 `tests/RevitModelessGuardRegression.cs`，证据为 `validation/revit-20261014-195855-cdd1f2b1/modeless-guard-regression-before.json`。当前编译通过，核心 35/35、独立 WPF 13/13；尚未安装和执行原生修复回归，不能提前声称窗口扫描已恢复。

安装后验证用户指定的三个测试模型：总图.0008_干净.rvt、厂房_干净.rvt、职工后勤楼_干净.rvt。核对独立窗口自动扫描、完整记录、项目保护和未预选依赖；本轮只读，不写入这些模型。

入口与操作流程沿用 [模型属性管理说明](Revit2020-0.2.0-模型属性管理.md)。模型必需性和属性必填性的依据边界见 [判定依据](模型检查判定依据.md)。版本包 `dist/Hifc.V1.Revit2020-0.2.1/` 与 0.2.0、0.1.0 分开保留。
