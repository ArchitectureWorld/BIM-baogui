**Goal:** 在同一新 RVT 上复现参考软件的工规 HIFC 映射，并提供可逐项复核的导出差异证据。

**Architecture:** 将当前参考配置冻结为唯一阶段基线。先验证来源参数、属性集归属和实际导出行为，再独立实现必要的 Revit 取数、参数准备和导出路径。所有 IFC 核验只读。

**Tech Stack:** Revit 2020 API、C#、Python、IFC4；依赖版本在实测工具建立时锁定。本阶段只要求 Revit 2020 实机验证。

**Spec:** 原交接文档 `D:\18_建模项目\湖北BIM云平台\反编译\_hifc\H-IFC插件开发交接技术文档.md`，以及用户在 2026-10-14 明确的阶段调整：先复现参考软件 HIFC 映射；官方补齐延后；用户后续提供新 RVT。

## Global Constraints

- 开发根目录：`D:\18_建模项目\湖北BIM云平台\V1`。
- 本期口径：参考配置 `config_backup1.tsv` 对应的工规映射。
- 参考输入契约保留原槽位、别名、同名取值、实例/类型优先顺序，具体行为以参考软件实测为准。
- 来源参数与 IFC 输出属性名是两个概念，保留 205 个取值来源的区分。
- 不以官方缺项作为当前复现阻断项；不引入官方词表或类型映射自动改写参考契约。
- 原始 `Reall`、`Integerl` 等先记录实际输出，不凭推测纠正；改动必须能解释对照差异。
- 几何转换复用 Revit IFC 导出路径，每轮调用一次；导出后的 IFC 不加工。
- 使用模型副本，写入前后有文档身份、旧值与文件证据；保持原件。
- 反编译代码只用于行为理解，新增实现独立编写，授权流程使用软件正常入口。
- 构造样例、旧版测试文件、配置静态检查均不能标记为参考软件实测通过。

## Review Focus

1. 同一 IFC 属性名对应不同来源参数时，检查别名取值，避免跨构件误写。
2. 同一 IFC 实体可匹配多个 Pset 时，检查按原槽位选择与通用挂载的实际规则。
3. 实例参数缺失、类型参数有值、两者同时有值时，检查优先顺序和空值行为。
4. 长度/面积、Real 与原始错误拼写，检查输出值、声明类型及单位，不仅检查名称出现。
5. Project/Building/Storey 与构件、模板与实例关系，检查属性实际 owner 与关系完整性。
