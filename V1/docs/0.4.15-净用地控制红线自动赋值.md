# 0.4.15 净用地控制红线自动赋值

手动将用地红线归为“规划控制线”后，名称和红线类型均自动填写建议值 **净用地控制红线**。点击写入后，两项真实保存到 Revit，并用于原生 IFC 导出。

## 修正行为

0.4.14 已接受正确枚举，但通用名称建议仍复制构件原生名“用地红线”，红线类型没有自动值。0.4.15 在所选构件赋属性和全面检查中共用同一条规则：

- 对已归为规划控制线，且原生名称、类型或业务值符合已确认净用地红线别名的对象，两个字段均要求“净用地控制红线”。
- 空值自动补齐；“用地红线”“净用地规划控制红线”等旧值显示纠正预览，状态为“规则待写入”。实际原值保留为写入核对基线。
- 通过正式写入事务保存，成功后回读；清空或改回错误值会被提示，已正确的重复分类不产生重复修改。
- 其他道路、建筑控制线不套用此值；规划净用地面积对象不会因此变成控制线。只读、重名冲突、共享类型修改仍按原保护规则处理。

这是本项目已明确的业务规则；冻结平台快照保持原样。本轮没有增加 Revit 持久参数或修改 IFC 文件文本。
