HIFC 0.5.0-Web · Revit 2020

1. 关闭 Revit，解压完整安装包，双击“安装 Web 版.cmd”。
2. 安装器校验文件与局域网服务器证书。尚未信任时，由你本人在证书窗口导入“当前用户 / 受信任的根证书颁发机构”。
   证书 SHA-256：34:F1:2F:72:97:D5:70:C3:64:1D:B2:DF:80:FF:67:55:D0:FF:09:AC:29:CF:13:12:11:21:D5:5A:E8:6F:E1:5F
3. 用 Revit 2020 打开模型副本，选择独立的“HIFC-V1-Web”页签 → “模型检查 / 属性管理”。
   首次发布者提示请核对 Hifc.Web.Revit.dll，由你本人选择“载入一次”。
4. 点击顶部“账号与连接”，首次登记只填手机号和真实姓名。左侧选模型分类，中间选构件，右侧编辑属性，然后预览并写入。写入后自动回读、复检，最后由你点击保存模型。

登记默认有效 168 小时。本机加密记住手机号和姓名；换电脑填写相同人员信息即可登录，原到期时间保持不变。
插件自动从 zetta 服务器检查并下载更新。关闭 Revit 后安装新版，下次启动生效；校验失败保留旧版，账号资料和草稿继续保留。
草稿保存在本机。复检或网络回执失败时保留结果，恢复连接后重新检查，不要重复写入。

入口：https://192.168.6.45:8443/
账号管理：https://192.168.6.45:8443/admin
管理员首次创建：在已配置 zetta-pc SSH 的电脑上运行“初始化管理员.cmd”，直接输入管理员手机号、姓名和 12–128 字符密码。
