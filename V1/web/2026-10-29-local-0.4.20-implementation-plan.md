# HIFC Web 0.4.20 parity implementation plan

> For agentic workers: execute task by task, retain a durable ledger, and independently review the integrated branch before delivery. The user explicitly authorized execution on 2026-10-29.

**Goal:** Deliver the approved Local 0.4.20 capabilities through the independent Web client and zetta service.

**Architecture:** Server owns business rules and signed plans; the client owns Revit API operations, model storage, UI and native export. The original six-file main update remains compatible; Node and platform synchronization are separate signed components served by zetta.

**Tech Stack:** Revit 2020/net48, netstandard2.0 shared contracts, .NET 10 server, PostgreSQL, Node 25.4.0, platform-sync 0.2.0-web.1.

**Spec:** [Approved design](2026-10-29-local-0.4.20-sync-design.md).

## Global constraints

- All development uses this HIFC-Web worktree. Local original checkout, installation and original models are preserved.
- Source snapshot commit: `fa88c56ce8eb5dd0d01406b220d06409ca9107ee`; imported Local source is read-only thereafter.
- ProtocolMajor 2; rule revision `reference-0.4.20-web2`; existing Web product/channel and six payload filenames retained.
- Fixed CA, existing update signing key, account identity/expiry and persisted drafts remain compatible.
- No browser credentials, private keys, model originals or runtime databases are committed or put into client packages.
- Native host and platform-write acceptance are separate; actual external replacement needs explicit target approval.

## Review focus

1. Old clients/old drafts cannot silently enter protocol 2 writes; values remain recoverable.
2. Definition migration or type-wide effects cannot escape signed prerequisites and transaction rollback.
3. User 0/false/blank/manual areas survive calculations, import, save/reopen and export.
4. An interrupted component install/update never replaces an active worker's runtime or erases state.
5. Platform model identity, editable status and explicit confirmation remain required at external mutation boundaries.
