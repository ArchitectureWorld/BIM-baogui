## 使用与边界

入口为 **H-IFC V1 → 模型属性管理 → 模型检查 / 属性管理**。人工选择报规阶段，模型类型可自动识别；点击全面检查，无需在 Revit 中预选构件。在清单中核对识别依据和补齐预览，确认写入后程序自动全面复检。

本轮只在副本执行写入，原始 RVT 未改变。成功案例对应关系只用于身份匹配且当前信息一致的对象；其他工程仅凭名称别名进入候选，不凭相同数字 ID 套用案例。停车位的通用模型与 IFC 的 IfcSpace 对应尚无足够证据，保留人工核对。

本轮证明识别及属性管理程序在指定案例上有效。完整多属性集 IFC 导出、参考软件同模型 A/B 和平台验收尚未执行；施工图规则与官方补充仍按既定范围后续处理。
