## 4. 文件说明

| 文件 | 用途 |
|---|---|
| `wuhan_planning_rules.v1.json` | 166 条完整规则；开发时的主数据源 |
| `wuhan_planning_properties.v1.csv` | 人工核对、筛选和评审 |
| `official_object_mappings.v1.json` | 官方提取出的 4 条显式对象映射 |
| `implementation_object_carriers.v1.json` | GH 版九类对象的稳定承载决策 |
| `GH_HIFC_SharedParameters.txt` | 我们自己的确定性共享参数定义 |
| `GH_HIFC_UserDefinedPsets.txt` | 带第三列 Revit 参数别名的 IFC Pset 配置 |
| `GH_HIFC_ParameterBindings.json` | 参数与 Revit 承载对象/类别绑定清单 |

## 5. 不能误读的数据

- `exampleValue` 是官方示例，不得自动写入正式模型；
- 当前数据不包含必填/有条件/建议级别；
- `implementation.*` 是 GH 版开发决策，不冒充官方字段；
- Organization 与 SpatialZone 不强行伪装成普通 Revit 构件，而由 canonical DataStore 和 IFC 后处理负责。
