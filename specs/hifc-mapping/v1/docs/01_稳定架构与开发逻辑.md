# GH / Rhino.Inside.Revit 官方插件兼容写入架构

> 本文替代旧版“Revit 原生 IFC + IFC 后处理”实施方案。旧方案与当前产品目标冲突，不再作为 GHA 开发依据。

## 1. 唯一目标

```text
指南与检查规则
→ GH 输入/计算
→ 按官方插件读取要求写入 Revit
→ 官方 H-IFC 插件导出 IFC
→ 官方检查软件正确识别
```

本项目不自研 IFC 导出器，不修改官方插件导出的 IFC，不用导出后补属性来弥补错误写入。

## 2. 证据模型

每条属性必须区分：

- `official`：官方规则提取出的 IFC 实体、PropertySet、属性名、数据类型和单位；
- `officialObjectMapping`：官方插件明确给出的 Revit→IFC 对象映射；
- `candidateProjection`：我们为实验生成的参数名、GUID、类别绑定和写入方式；
- `verification`：Revit 回读、官方插件导出和检查软件识别状态。

只有 `official` 和 `officialObjectMapping` 可直接称为官方证据。候选参数和 UUIDv5 GUID 在完成官方软件闭环前均为未验证实现决策。

## 4. 当前官方对象证据

| IFC 实体 | 官方显式 Revit 对象映射 | 当前策略 |
|---|---|---|
| IfcProject | ProjectInformation | 允许候选写入，待官方导出验证 |
| IfcBuilding | ProjectInformation | 允许候选写入，待官方导出验证 |
| IfcBuildingStorey | Level | 必须指定 Level |
| IfcSpace | Room | 必须指定 Room |
| IfcOrganization | 未确认 | 阻断 |
| IfcSite | 未确认 | 阻断 |
| IfcSpatialZone | 未确认 | 阻断 |
| IfcDoor | 未提取到显式映射 | 阻断正式兼容声明 |
| IfcDuctSegment | 未提取到显式映射 | 阻断正式兼容声明 |

“阻断”表示当前证据不足，不能把数据写到任意宿主后宣称官方插件会识别；不表示标准中不需要该实体。

## 5. Stage 01 文件初始化

### 5.1 标准字段

所有非空 IfcProject 标准字段必须从 Stage 01 字段注册表动态解析，禁止维护少量硬编码字段表。字段无法映射时必须失败或进入明确的登记例外。

IfcOrganization 数据保留在初始化载荷中；在官方插件组织对象协议确认前，不压平写入 ProjectInformation。

### 5.2 工作流字段

以下数据只属于 HBR 工作流，不冒充 IFC 属性：

- FileGuid；
- 子项和文件身份；
- 模型文件类型；
- WorkflowVersion；
- FileContextHash；
- 规则包版本；
- 激活/不适用规则；
- 初始化状态。

它们进入 HBR_FileContext 与 Revit Extensible Storage。

### 5.3 规划目标

规划目标与模型实际值分离：

```text
目标：容积率 ≤ 2.00
实际：容积率 1.83
```

Stage 01 保存目标；后续模型计算产生实际值。不得将目标数值写成实际指标。

### 5.4 坐标

```text
X = 南北坐标 = NorthSouth
Y = 东西坐标 = EastWest
```

读取、写入、共享参数投影、回读和 Golden 样本必须保持一致。

## 6. 写入事务

每次写入必须执行：

```text
Validate
→ 根据 IFC 实体解析目标对象
→ TransactionGroup
→ 安装/校正候选参数定义与类别绑定
→ Parameter.Set
→ Regenerate
→ 按 GUID 回读
→ Commit / Assimilate
→ 任一失败整体 RollBack
```

Revit 回读通过后的状态只能是：

```text
REVIT_WRITE_VERIFIED
```

不得显示为官方兼容通过。

## 7. 通用写入规则

- IfcProject/IfcBuilding：未提供 ElementId 时可使用 ProjectInformation；
- IfcBuildingStorey：必须提供 Level Id；
- IfcSpace：必须提供 Room Id；
- 其他未确认实体：返回 `BLOCK_PENDING_OFFICIAL_PLUGIN_CONTRACT`；
- 一个请求包含多类属性时，必须按属性分别解析目标，禁止把所有属性写到同一目标列表；
- Length/Area/Volume/Angle 分别按 m/m²/m³/° 输入并转换为 Revit 内部单位。

## 8. 最终验证

完整链路：

```text
Golden RVT
→ 官方插件导出
→ Golden IFC
→ 官方检查软件
```

逐字段核对：

- IFC 实体；
- PropertySet；
- 属性名；
- 数据类型；
- 单位；
- 值；
- 对象关系；
- 检查软件状态。

只有完成上述闭环的字段才能标记 `OFFICIAL_EXPORT_VERIFIED` 与 `CHECKER_VERIFIED`。

## 9. v1 完成定义

1. 166 条官方规则可载入并通过 schema/交叉校验；
2. Stage 01 非空 IfcProject 字段无静默遗漏；
3. X/Y 坐标语义正确；
4. 非项目属性不会默认落到 ProjectInformation；
5. 未确认实体明确阻断；
6. Revit 写入、单位转换、回读和回滚有自动化测试；
7. 至少建立一个 Golden RVT；
8. Golden RVT 由官方插件生成 Golden IFC；
9. 官方检查软件正确识别目标字段。
