## 使用

在 Revit 中打开项目，进入 **H-IFC V1 → 模型属性管理 → 模型检查 / 属性管理**。

1. 人工确认报规或施工图阶段。
2. 自动识别或人工选择总图、单体建筑。
3. 全面检查当前模型，在窗口中定位构件、调整类目和属性。
4. 点击“写入 Revit”，回读并全面复检，再按需要保存 RVT。

不要求预先选择构件。可从模型取得的面积、名称等自动填入；人工草稿为红底，已手工写入为橙底。阶段、类型、检查及未写入修改按模型暂存。

非标准模型也可在 Revit 选中后使用“选中构件赋属性”。报规人防区域、消防分区、停车场和停车位使用面积（Area）载体；地下建筑区域仍使用楼板。点击“地下楼层 / 基准”确认实际楼层和地坪基准后，生成地下层数、高度建议，确认记录按模型暂存。

**目前仅道路宽度要求人工填写，并在未填时将左侧对应类目标红。** 其他字段保留自动取值、状态展示和人工修改，不额外增加强制手填要求。检查只涉及模型与属性，不涉及材质、贴图或渲染资源。

## 开发和安装

需在装有 Revit 2020、.NET SDK 和 .NET Framework 4.8 开发环境的 Windows 上构建：

```powershell
pwsh -File V1/tools/Build.ps1
pwsh -File V1/tools/Install-Revit2020.ps1
```

安装前正常关闭 Revit。也可运行 [`V1/安装并体验UI.cmd`](V1/安装并体验UI.cmd)。

GitHub Actions 执行核心、独立 WPF 和 Python 回归；Revit 实机验证在本机模型副本中执行。
