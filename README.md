## 使用

在 Revit 中打开项目，进入 **H-IFC V1 → 模型属性管理 → 模型检查 / 属性管理**。

1. 人工确认报规或施工图阶段。
2. 自动识别或人工选择总图、单体建筑。
3. 全面检查当前模型，在窗口中定位构件、调整类目和属性。
4. 点击“写入 Revit”，回读并全面复检，再按需要保存 RVT。

不要求预先选择构件。可从模型取得的面积、名称等自动填入；人工草稿为红底，已手工写入为橙底。阶段、类型、检查及未写入修改按模型暂存。

点击“导出项目 IFC”后选择保存路径，在核对窗口查看缺失输入及本次 IFC 面积，再确认导出。未写入的手工草稿先通过“4 写入 Revit”处理；全项目范围包含 Area 及未分类几何，不受预选或当前视图过滤影响。报规总图的绿化楼板可默认归为绿地，楼板也可手动指定规划控制线。

非标准模型也可在 Revit 选中后使用“选中构件赋属性”，包括人工指定专用窗。报规人防区域、消防分区、停车场和停车位使用面积（Area）载体；地下建筑区域仍使用楼板。地上地下作为同一栋建筑表达，点击“楼层 / 基底 / 基准”确认实际地下楼层、基底楼层及地坪基准，记录按模型暂存。已有明确值优先保留。

**“建筑用途名称”缺失时，左侧建筑技术项和右侧属性标红；填写并写入、全面复检后解除。** 该值按项目实际用途确认，不能用“民用建筑＝否”代替用途分类修复。“区内道路类型＝消防道路”的道路宽度仍要求手填并标红；普通道路和道路红线不适用该要求。其他字段保留自动取值、状态展示和人工修改。只检查模型与属性，不涉及材质、贴图或渲染资源。

## 开发和安装

需在装有 Revit 2020、.NET SDK 和 .NET Framework 4.8 开发环境的 Windows 上构建：

```powershell
pwsh -File V1/tools/Build.ps1
```

构建仅生成预览包，不自动安装。正式安装脚本固定使用已经保留的 0.4.16 稳定包，需先正常关闭 Revit；预览源码的一键构建安装入口会明确阻止自动安装。

稳定包为 V1/dist/Hifc.V1.Revit2020-0.4.16/。预览构建输出 V1/dist/Hifc.V1.Revit2020-0.4.17-preview.2/，隔离宿主验证不替换正式 DLL。详见 [属性与资料开发记录](V1/docs/revit-property-data.md)。

GitHub Actions 执行核心、独立 WPF 和 Python 回归；Revit 实机验证在本机模型副本中执行。
